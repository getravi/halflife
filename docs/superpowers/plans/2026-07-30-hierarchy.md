# halflife Hierarchy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two-row header (app row / path row), halflife branding, Paths as universal landing, My-paths grouping on the homepage.

**Architecture:** Row 1 stays the static `.nav` in index.html, cut down to app-level links. Row 2 is a new `.path-bar` element whose entire content (switcher + Today + phases + Cards/Terms/Notes) is generated by `renderNav`, and whose visibility nav.js toggles per hash. Landing collapses to "no hash → #paths".

**Tech Stack:** unchanged (vanilla ES modules, Vite, Vitest, Worker).

- [ ] **Step 1: Update tests** — renderNav assertions become:

```js
describe('renderNav', () => {
  const catalogue = { paths: [
    { id: path.id, title: 'This one', phases: [] },
    { id: 'other', title: 'Other one', phases: [{ id: 'o-p0', title: 'O' }] }
  ] };

  it('builds the whole path bar: views plus one link per phase', () => {
    const bar = capture(root => renderNav(path, root, catalogue));
    for (const [href, label] of [['#today', 'Today'], ['#cards', 'Cards'],
        ['#glossary', 'Terms'], ['#notes', 'Notes']]) {
      expect(bar).toContain(`href="${href}">${label}`);
    }
    for (const ph of path.phases) expect(bar).toContain(`href="#${ph.id}"`);
  });

  it('offers a path switcher when the catalogue holds more than one path', () => {
    const bar = capture(root => renderNav(path, root, catalogue));
    expect(bar).toContain('nav-path-switcher');
    expect(bar).toContain('Other one');
    expect(bar).toMatch(new RegExp(`value="${path.id}"[^>]*selected`));
  });

  it('renders no switcher when there is only one path', () => {
    const one = { paths: [{ id: path.id, title: 'Only', phases: [] }] };
    const bar = capture(root => renderNav(path, root, one));
    expect(bar).not.toContain('nav-path-switcher');
  });
});
```

### Task 3: nav.js — visibility + active state across both rows

**Files:**
- Modify: `src/nav.js`
- Test: `test/dom/nav.test.js` (extend)

**Interfaces:**
- Consumes: `#path-bar` element (Task 1), links inside it (Task 2).

- [ ] **Step 1: Implement** — in `apply()`:

```js
const APP_VIEWS = new Set(['#paths', '#settings', '#account']);

  const apply = () => {
    const hash = window.location.hash || '#paths';
    const id = 'view-' + hash.slice(1);
    document.querySelectorAll('.view-panel').forEach(v =>
      v.classList.toggle('active', v.id === id));
    document.querySelectorAll('.nav a, .path-bar a').forEach(a =>
      a.classList.toggle('active', a.getAttribute('href') === hash));
    // The path bar belongs to a path; app-level views hide it.
    const bar = document.getElementById('path-bar');
    if (bar) bar.hidden = APP_VIEWS.has(hash);
    window.scrollTo(0, 0);
  };
```

Note the default hash flips from `#today` to `#paths` here too.

- [ ] **Step 2: Implement** in `pathCardsHtml`:

```js
export function pathCardsHtml(catalogue, enrolledIds, signedIn) {
  const all = catalogue.paths ?? [];
  const mine = all.filter(p => enrolledIds.has(p.id));
  const rest = all.filter(p => !enrolledIds.has(p.id));
  const cards = ps => ps.map(p => card(p, enrolledIds, signedIn)).join('');
  if (!mine.length) return cards(all);
  return `<div class="path-section-title">My paths</div>${cards(mine)}${
    rest.length ? `<div class="path-section-title">Explore</div>${cards(rest)}` : ''}`;
}
```

(where `card()` is the existing per-card template extracted into a helper).
CSS: `.path-section-title { font-family: var(--mono); font-size: 11px;
color: var(--muted); text-transform: uppercase; letter-spacing: .08em;
margin: 18px 0 4px; }` with first-child margin-top 0.
